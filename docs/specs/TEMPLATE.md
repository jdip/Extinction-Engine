# Title

## Research

Current behavior, constraints, affected files or systems, risks, unknowns, and
prior related work.

## Plan

Ordered steps, boundaries, rollback notes, and test strategy.

## Implement

Concrete changes made and any deviations from the plan.

## Test

Automated tests to add or update, plus relevant existing tests that cover the
touched behavior.

## Validate

Commands run, pass/fail evidence, environment used, skipped checks with
reasons, and residual risks.
